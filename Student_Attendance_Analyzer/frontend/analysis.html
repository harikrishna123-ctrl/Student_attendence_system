📚 Mathematical Definition of Sets

Let U be the Universal Set comprising enrolled students in the selected class and section.

  • Set A = { s ∈ U | Student s is Present on the evaluated date }
  • Set B = { s ∈ U | Student s is Absent on the evaluated date }
  • A ∪ B = U and A ∩ B = ∅ for single-subject attendance.
